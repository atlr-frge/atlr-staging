Our own software

From script to reviewed cut.

Conformer and Conduit are Atelier’s own engine, brought into production jobs as existing IP and run inside the client’s production. The same records and review sit behind every output.

Conformer

Reads Fountain and Final Draft screenplays and breaks each scene into beats. Standard coverage patterns turn each beat into a shot list, with camera moves mapped to what each model can do. Characters, locations, props, sounds and effects are held as versioned references that every prompt draws on, and each shot is compiled into a prompt for the model it is sent to, on a cloud lane or a local GPU lane, under spending caps.

Screenplay → scenes and beats → shot list → prompt per model → takes with their record

Conduit

Where people review. A person accepts or rejects each take, logged with who and when, and the cut goes to DaVinci Resolve as XML or OpenTimelineIO. Each take keeps its model, prompt and settings, with fields for cost, canon references and validation scores. One Conduit per production, each with its own database, storage and login, so no client’s work can reach another’s.

Review → accept or reject → cut in Resolve → numbered, checksummed release
On every job

Five controls, every build.

The same controls run in the financial-crime builds, where the approvals and the record are what an examiner will ask for, and in the broadcast and music builds. The model-risk evidence pack that ships with an engagement is assembled from these records.

01Validation before use

Before go-live at an institution, the financial-crime system runs against that institution’s own filed reports and the miss rate goes to the compliance officer.

In production work, fourteen upscalers were scored against a 4K reference for a network series. The closest became the default, and generative ones run per shot, with sign-off.

02Human approval

In the financial-crime work, model output can reach a filing by one route only: the narrative the analyst edits and the compliance officer approves.

A person accepts or rejects generated takes in review, and the archive agent’s drafts wait on a review page until a person has seen them.

03Audit record

Every model call and human decision is written to a hash-chained audit record.

Each generated take keeps its model, prompt and settings, and its cost where the provider reports it; each accept or reject is logged with who and when.

04Release control

Every release passes automated tests and a health check before it rolls out.

Each delivery is cut to a new numbered folder by a script that refuses to overwrite, and every copy into a release is checked by SHA-256.

05Data protection

Personal information is tokenised before any model call, and routing is restricted in code to approved Canadian regions.

Client material stays under each production’s confidentiality terms, inputs are hash-checked against their source, and review sites decrypt only in the viewer’s browser.
